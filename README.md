本系統為專為 ERP 課程與檢定/實務練習打造的 **1:1 高保真度互動式模擬系統**，完整仿造「Conductor 配銷模組」之畫面外觀、配色規範、多視窗 MDI 操作與全流程業務邏輯。

---

## 🚀 系統快速啟動方式

### 1. 下載 / Clone 專案
將專案放置於 XAMPP 的 `htdocs` 目錄下（例如 `C:\xampp\htdocs\erp`）：
```bash
git clone https://github.com/tailing-cloud/workflow-erp-conductor.git C:\xampp\htdocs\erp
```

### 2. 啟動 XAMPP 環境
- 啟動 **XAMPP Control Panel**
- 確保 **Apache** 與 **MySQL** 服務已正常啟動

### 3. 初始化資料庫
在瀏覽器打開以下網址，系統將自動建立資料庫 `erp_db` 及所有資料表，並寫入基礎種子資料：
```
http://localhost/erp/init_db.php
```

### 4. 系統登入與開始使用
- 打開瀏覽器輸入：`http://localhost/erp/` 或 `http://127.0.0.1/erp/`
- **自訂帳號**：輸入任意帳號（例如輸入 `B05`、`B18`、`B20`），系統若未看過該帳號將**自動建立新帳號**！
- **公司自動同步**：若帳號以 `B` 開頭（如 `B05`），公司別欄位將**自動同步選取為 `學生區B05`**！
- **密碼**：可自訂密碼或留空直接登入。

## 🎯 建議練習流程 (標準配銷操作順序)

1. **登入系統**：輸入您的學生帳號（如 `B05`），系統自動指派 `學生區B05`。
2. **檢視/維護基礎資料**：
   - 開啟 `COPI01` 查看客戶 `1109 上奇科技`。
   - 開啟 `INVI02` 查看品號 `900006 Insta360 Flow 2` 與售價/進價設定。
3. **開立客戶訂單**：
   - 開啟 `COPI06`，確認訂單 `A221-202611001` 下訂 20 台。
4. **批次轉請購單**：
   - 點擊工具列【轉請購】或在流程圖開啟 `COPB10`，輸入請購單別 `C311`，按【確認】。
5. **批次更新請購單產生採購單**：
   - 開啟 `PURB01`，選擇鎖定選項 `1 | 已鎖定`，輸入採購單別 `C331`，按【確認】。
6. **檢視佇列日誌**：
   - 開啟 `佇列工作控制台`，查看背景處理狀態與 Commit 記錄。
7. **採購與進貨驗收**：
   - 開啟 `PURI07` 檢視採購單 `C331-202611001`。
   - 開啟 `PURI09` 完成進貨驗收與品號入庫。
8. **銷貨出貨**：
   - 開啟 `COPI08` 完成銷貨單 `A231-202611001`。
9. **全流程樹狀追蹤查驗**：
   - 開啟 `COPQ05`，點擊【展開】，驗證整條訂單鏈路完整串聯！
